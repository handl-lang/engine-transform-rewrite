# Reference

## Public API

| item | what it is |
|---|---|
| `RewriteEngine::run_pass` | run one named pass over the arena |
| `TransformRule::Native(name)` | dispatch a rule to a wired `NativeRewrite` |
| `with_desugar_natives` | install the built-in desugar native rules |
| `RuleSource` | where a pass's `TransformDef`s come from |

## Crate

| crate | role |
|---|---|
| `hnl-engine-transform-rewrite` | engine implementation |

## Build and test

```bash
cargo build     # sibling [patch] tables resolve deps from ../<repo>
cargo test      # cargo test
```

Dependencies are git deps on `branch = "main"`; locally the `[patch]` tables
point at sibling checkouts (regenerated by `host/scripts/dev-link.sh`).
